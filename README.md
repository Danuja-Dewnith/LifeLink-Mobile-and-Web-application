🩸 LifeLink – AI Smart Blood & Organ Donation System

LifeLink is a mobile and web-based healthcare platform designed to modernize blood and organ donation using artificial intelligence and real-time technologies.

The system connects donors, patients, and healthcare professionals through a centralized platform that enables real-time alerts, intelligent donor-recipient matching, and AI-based health prediction.

🚀 Key Features
🔔 Real-time emergency notifications
📍 GPS-based donor-recipient matching
🤖 AI-powered organ health prediction
💬 AI chatbot for 24/7 support
👨‍⚕️ Doctor instruction & guidance system
📊 Donation tracking and history
🛠️ Technologies Used
Flutter (Mobile App)
Node.js & Express.js (Backend)
MongoDB (Database)
AI / Machine Learning
Gmail API (Notifications)
🎯 Goal

To reduce response time in emergencies, improve donor management, and ultimately save more lives through intelligent healthcare technology.
